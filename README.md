# 群演 · 社会演化实验室

中文纯数值社会模拟器。从个体天资、学习、交易、轻量雇佣和代际传递出发，观察财富差距、市场竞争与代际流动。默认 2,000 人，按月模拟 300 年。

## 使用

- 左侧设置人口、种子、初始财富分布与演化机制，然后新建世界。
- 开始、暂停、单月或一年推进；所有计算都在浏览器的 Web Worker 中进行。
- 时间轴支持拖动、输入累计月数或逐月切换，回看已完成的任意月份。社会、市场、代际指标与个体及家族资料一起切换；返回最新时刻后继续演化。
- 在散点图或个体列表中打开个体，查看天资、技能、收支和家族。关注后开始记录逐月轨迹。
- 暂停并修改一个机制，建立对照；原始规则和修改后的世界同步运行。
- 本机存档使用 IndexedDB。JSON 导出包含完整随机状态、月度汇总、谱系及对照世界，可跨浏览器恢复。
- 历史查询保存回溯起点与规则、关注操作记录，并使用最多 8 个稀疏内存检查点加速确定性重放，不保存每个人每月的完整副本。查询不会修改最新世界，长距离回看可随时改选月份或返回最新。
- 缺少时间轴记录的旧存档保留完整月度汇总曲线，但无法可靠还原早期个体状态；时间轴从其导入月份开始。新存档导入后保留原有的完整回溯范围。
- 多种子实验为 20 个种子 × 6 组规则，可随时停止并导出已完成结果。

## 本地开发

需要 Node.js 24+（数值测试使用原生 TypeScript 加载）。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 3000
npm test
npm run typecheck
npm run lint
npm run build
```

本地地址：http://localhost:3000/

运行全部数值对照：`npm run experiments`。默认每个情景采用 160 人、300 年，20 个种子；结果保存到 `tests/experiment-results.json`。不同人口规模的市场集中度不能直接等同。

## 模型约定

- 三个抽象市场分别提供生活、学习与生产增益；无具体商品、银行或股票系统。
- 初始天资近似 N(50,15²)，每个维度限制在 0—100。财产不均开局独立生成，保持人口、天资、随机状态和总现金与平等开局一致。
- 天资每年调整不超过 0.5、终身不超过 ±8；技能通过实践增长，有饱和与遗忘。
- 固定寿命 80 年，18—65 岁劳动；每次死亡补充新生儿，育龄双亲随机选择。未满足生活需求影响表现，不改变寿命。
- 雇佣是按月重选的收益分成。成交收入 80% 按贡献分配，20% 归组织者；独立生产者取得全部收益。
- 固定现金总量；产出、资本、消费与折旧分别记账。资本按生产增益市场现价估值，因此资产估值也随价格变化。
- 代际指标使用 50 岁时相对于 45—55 岁同龄组的财富分位；父母行按双亲分位平均值分组。仅在模拟中出生、资料完整的子代进入统计。
- 浮点记账允许相对 1e-7 的误差容限，界面将绝对值小于 1e-8 的值显示为 0。
- 市场集中度、财富分位和阶级指标都是观察结果，不参与生产奖励。没有出现垄断也属于有效实验结果。

## 实现与验证

`lib/simulation` 包含纯数值引擎、状态类型、Worker 协议与本机存档。`app/workbench.tsx` 为工作台，`components/lab-charts.tsx` 为数据图表。

测试覆盖确定性、存档恢复、遗传方差、可塑性、人口与账目守恒、继承、雇佣有效性、无供给/无现金、分支和 Worker 通信。生成的 shadcn 组件保持原样，静态检查只检查项目拥有的代码。

研究结果仅适用于这些合成规则，并非现实社会预测。参考：[基于主体的计算经济学](https://faculty.sites.iastate.edu/tesfatsi/archive/econ308/tesfatsion/)。
