# 群演 · 社会演化实验室

从个体天资、交易与代际传递出发，观察财富差距、市场集中和社会流动如何形成。

一个中文、纯数值的社会模拟工作台。默认 **2,000 人 × 300 年，逐月演化**；你设定基本规则，再用时间轴、个体记录和对照实验检验结果。所有个体决策由数值引擎完成，无需大模型或 API Key。

![群演真实操作演示：演化、天资与财富、历史回看及个体观察](assets/demo.gif)

演示为实际浏览器录制，展示同一世界的演化与历史回看；计算等待经过剪辑。查看[清晰版视频](assets/demo.mp4)。

## 项目特点

- **社会结果从互动中产生。** 三个市场、有限信息搜索、自主报价、资本投入与按月雇佣共同影响收益；没有预设富人、垄断者或阶级奖励。
- **天资有差异，成长有边界。** 八项独立出生属性、三个领域技能；基础属性每年最多变化 0.5 点、终身最多偏移 ±8。遗传、家庭培养和财产继承可以分别调节。
- **随时回到已模拟的月份。** 拖动时间轴或输入月份，同步查看当时的社会指标、散点图、市场与个体资料，再返回最新时刻继续实验。
- **从社会统计追到一个人。** 财富基尼与市场集中度分别展示；“天资 × 财富”可切换六项综合、认知综合或单项属性。点击个体查看收支、技能、亲属和人生节点。
- **用对照检验机制。** 暂停后复制世界、改变参数，比较两条真实演化轨迹；也可运行 20 个种子 × 6 组规则，查看结果分布。
- **实验留在本机，可以复现。** Web Worker 负责计算，IndexedDB 保存进度，JSON 导出包含随机状态与回溯记录；相同种子和参数得到相同结果。

## 一键运行

### Windows：双击启动

1. 首次使用先安装 [Node.js 24 LTS](https://nodejs.org/en/download) 或更新版本，保留安装器的默认选项。
2. 在本仓库点击 **Code → Download ZIP**，将压缩包**完整解压**到任意目录。
3. 双击根目录的 **`start.cmd`**。它会自动安装依赖、构建网站并打开浏览器。

启动后访问 **[http://localhost:3000/](http://localhost:3000/)**。首次准备需要联网，耗时取决于下载速度；以后依赖未变化时会跳过安装。无需配置数据库、登录服务或密钥。

保持启动窗口开启，按 **Ctrl+C** 停止服务。关闭网页前点击工作台右上角的「保存」；下次打开后点击「恢复」。更新代码后，先停止原服务，再双击启动文件。

### macOS / Linux / 命令行

安装 Node.js 24+ 和 Git 后，执行：

```sh
git clone https://github.com/CodercatZjw/social-simulator.git
cd social-simulator
npm run launch
```

下载 ZIP 并解压也可以；在解压目录运行 `npm run launch` 即可完成依赖安装、构建与启动。Windows 同样支持这条命令。

端口被其他程序占用时，可改用 `npm run launch -- --port 3001`，然后访问 [http://localhost:3001/](http://localhost:3001/)。已有群演服务时，启动器会复用它；`--no-open` 可关闭自动打开浏览器。

## 第一次实验

点击「开始演化」，运行几年后暂停，将散点图切到「天资 × 财富」，再拖动时间轴回看初始状态。返回最新时刻，修改「财产继承比例」并建立对照分支，继续运行，观察两个世界的差异。

天资综合值仅用于图表观察，不参与收益计算。天资坐标变化缓慢，财富和颜色更容易反映短期变化。代际样本需要几十年积累，资料不足时显示「样本不足」；长距离历史查询需要等待确定性重放完成。
